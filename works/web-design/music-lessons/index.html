Lesson 「授業内容」

キッズ・ジュニア音楽基礎コース（未就学児〜小学生）

音楽を大好きになるところからスタート。現役プロによる実践的かつ楽しい指導で、リズム感や音感を遊び感覚から本格派まで丁寧に育てます。初めて楽器に触れるお子様でも安心です。

本格ステージ・コンクール挑戦コース（小・中・高校生）

高度な演奏技術を磨き、表現力を高めるための専門コース。一流講師陣が,お子様の個性を引き出しながら、オーディションやコンクール、将来のプロの道まで見据えた指導を行います。

【人気】親子で奏でるペアレッスンコース（保護者様料金半額）

お子様のレッスンに保護者様も一緒に参加し、お互いに一人の「生徒」として切磋琢磨できる大好評のプランです。親が真剣に楽器に向き合う姿を見せることで、子どもは「挑戦する楽しさ」や「継続の大切さ」を自然と学び取り、共に成長するパートナーとしての深い信頼関係が生まれます。

Part 「開催パート・科目」

  • リトミック

    音楽に合わせて体を動かし、幼児期に大切なリズム感・表現力・集中力を心と体全体で自然に育みます。

  • ピアノ

    クラシックからポップスまで、正しい手の使い方や美しい音の出し方をマンツーマンで基礎から指導します。

  • アコースティックギター

    コードの押さえ方からソロ演奏まで。お子様の体のサイズに合わせたミニギターのレッスンも対応しています。

  • ドラム・パーカッション

    全身を使ってリズムを刻む楽しさを体感。ドラムを叩くことで、抜群のテンポ感と集中力が身につきます。

  • ヴォーカル・歌唱

    正しい呼吸法や発声を学び、豊かな表現力で伸びやかに歌う楽しさを伝えます。音痴克服や合唱対策にも。

  • ソルフェージュ・楽典

    楽譜を正しく読む力、音を聴き取る力を養います。すべての楽器演奏の土台となり、音楽の理解を深めます。

Q and A 「よくある質問」

Q : 親が全くの初心者です。子どもにカッコ悪い姿を見せることになりませんか？
A : むしろ、その姿が最高の教育につながります！最初から完璧にできる大人はいません。親御様が「上手にできなくて悔しい、精度を上げたらできた！」というプロセスをリアルに見せることで、お子様も「間違えてもいいんだ」「諦めずにやってみよう」と強く励まされます。先生に素直に教わるお父さん・お母さんの姿は、お子様の目にも新鮮で、とても素敵に映るはずです。
Q : 楽器を持っていませんが、レッスンを受けられますか?
A : はい,可能です。当スクールでは、お子様用のミニ楽器から大人用まで、すべて無料でレンタル可能なサービスを行っております。また,成長に合わせた楽器選びに関するご相談も承っておりますので、まずは手ぶらでお気軽にお越しください。
Q : 下の子の送り迎えなどがあり、スケジュールが心配です。
A : 当スクールは振替レッスン制度が充実しています。また,親御様が「親子ペアレッスン」を受講される場合は、同じ時間帯に枠を調整することも可能ですので、送迎の待ち時間を無駄にすることなく有効活用していただけます。
Q : レッスン料金はいくらですか？親子で受けると高くなりますか？
A : コースや回数によって異なりますが、当スクールでは家族応援として「親子ペア割引」をご用意しております。お子様と一緒に受講される場合、保護者様の一レッスン料金はなんと【半額】となります！ご家族で無理なく音楽をスタートできるようサポートしておりますので、詳細は無料体験時にお気軽にお問い合わせください。
