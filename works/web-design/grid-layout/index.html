  • モダンワークデスク

    広々としたL字レイアウトで作業効率がアップ。スタイリッシュなグレーのメッシュチェアが快適なデスクワークを支えます。

  • レトロポップ・デスク

    温かみのある木目調デスクに充実した収納棚をセット。趣味やクリエイティブな作業に没頭できる空間を作ります。

  • ナチュラルウッド

    自然光になじむ明るい木目が特徴。オープンシェルフとセットで、お部屋に清潔感と開放感を与えてくれます。

  • アンティークデスク

    味わい深い重厚な木目と細部までこだわった引き出し収納。歴史を感じさせる重厚感で特別な書斎空間を演出します。

  • ミーティングデスク

    透明感のあるガラス天板とスチール脚の組み合わせ。オフィスやミーティングスペースに都会的でスマートな印象を与えます。

  • モノトーン

Chair

  • ヘルゴード

    伝統的なボタンタフティングと深みのあるバーガンディレザーが放つ重厚感。お部屋にひとつ置くだけで、ラグジュアリーな書斎の雰囲気を演出します。

    優美な曲線のウッドフレームと、やわらかなベロア調クッションの組み合わせ。コンパクトながら存在感があり、ドレッサーやディスプレイ用にも最適です。

    鮮やかなターコイズブルーと温かみのある木脚が目を引くミッドセンチュリーデザイン。日常のダイニングに心地よいリズムと彩りを添えます。

  • モデルナ

    身体をすっぽりと包み込む有機的なフォルム。360度どこから見ても美しく、モダンなインテリアの主役になるデザインチェアです

  • ミニマル

    低めの座面と優しいグレーのファブリックが醸し出す開放感。視線を低く保つことで、お部屋をより広くゆったりと感じさせてくれます
