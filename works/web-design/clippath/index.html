SDGS「未来へつなぐ、緑の記憶。」

都市の利便性と、豊かな生態系の維持を両立させる。それが私たちの掲げる開発目標です。

地域の植生を活かした街づくりは、四季の移ろいを感じさせ、住む人の心に深い安らぎをもたらします。

長く住み続けられる「長寿命な街」をつくることは、廃棄を減らし、価値を維持し続けるSDGsの体現に他なりません。

そんな100年先も色褪せない、持続可能な理想郷をカタチにします。

PROJECT 「事業内容」

エシカル・フォレスト 結（ゆい）

全住戸に再エネを導入し、既存樹木を活かした設計で生態系を保全します。住むことが地球への貢献となる、サステナブルな誇りと深い安らぎを次世代へとつなぐ循環型街区です。

セントラル・グリーン・レガシー

広大な緑地と調和した強固な建築により、持続可能な住環境を実現します。環境負荷を最小限に抑えつつ、住み手の品格を映し出す、真の豊かさを追求しました。

BLUE & GREEN 100th ミライ街

水と緑、そして都市機能が高度に融合したSDGsモデル地区。先進技術で脱炭素を推進し、自然の恩恵を五感で享受する暮らしを提案します。住まう人が人生に誇りを持ち、100年続く安心を約束する先端的都市です。

Q and A 「よくある質問」

Q : 100年続く街にするために、具体的にどのような工夫をしていますか？
A : 耐久性の高い構造の採用に加え、経年変化を楽しめる自然素材を使用しています。また、ライフスタイルの変化に柔軟に対応できる可変性の高い設計を導入しています。
Q : SDGsを意識した街づくりは、住人にどんなメリットがありますか？
A : 高い断熱性や省エネ設備により光熱費が抑えられ、豊かな緑が心身の健康を促進します。環境に配慮した暮らしが、将来的な資産価値の維持にもつながります。
Q : 開発による環境破壊への対策はどうなっていますか？
A : 既存の樹木を移植・保全するほか、屋上緑化や透水性舗装を採用。地域の生態系を壊さず、むしろ多様な生物が共生できる「都市の森」を再構築する方針です。
Q : 自然環境との調和は、都市の利便性を損ないませんか？
A :いいえ。最新テクノロジーによるスマートシティ化と緑地配置を両立させています。自然の癒やしを感じながら、快適に暮らせる「新しい都市の形」を目指しています。
Q : 居住者がSDGsに貢献できる取り組みはありますか？
A :共有部でのコンポスト設置や、住民専用のシェアリングサービスを提供しています。日々の暮らしの中で、無理なく自然にサステナブルな活動に参加いただけます。
